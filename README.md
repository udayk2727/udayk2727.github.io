# Uday Kiran — Personal Portfolio

A responsive, static portfolio for **Uday Kiran Kodeboyina**, showcasing Generative & Agentic AI, Data Science, Oracle engineering, and selected projects.

## Preview locally

Open `index.html` in Chrome, Firefox, or Edge. No installation or build step required. The site uses Google Fonts if internet is available, with local font fallbacks.

## Publish with GitHub Pages

1. Sign in to GitHub as `udayk2727`.
2. Create a **public** repository named **`udayk2727.github.io`** (separate from your `udayk2727` profile README repository).
3. Upload `index.html`, `styles.css`, and `script.js` to the repository **root**, and commit. You can also upload this README.
4. Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
5. Select branch `main`, folder `/(root)`, then **Save**.
6. When GitHub Pages finishes deploying, visit **https://udayk2727.github.io/**.

## Customize

- `index.html`: edit the intro, experience descriptions, project details, and URLs.
- `styles.css`: change theme, colors, typography, and layout.
- Add a verified resume PDF in the repository if you want to include a `Download Résumé` button. Avoid publishing phone numbers or addresses unless you want them public.
- Check each repository's live content for accuracy before sharing with recruiters; the Taxi and Quantum repositories are labeled as forks.

No analytics, tracking pixels, or contact-form back end are included. The email button uses `mailto:`.
